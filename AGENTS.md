This repo uses Ank: tasks and decisions live in `.ank/`.

Research papers (3DGS, SLAM/VIO) live in `docs/research/`: one folder per paper with a reading note (`fiche.md`) and the full text (`paper.md`). Start with `docs/research/INDEX.md`. When code relies on a paper, cite its citekey and page in a comment. To add a paper, follow "Ajouter un papier" in `docs/research/README.md` (one command for arXiv: `python docs/research/outils/fetch_arxiv.py <arxiv_id> <citekey> <axe>`).
