Suite de SP-0 (décision du 2026-10-12) : l'aperçu live s'entraîne sur les poses du casque, sans SfM ; le risque se
déplace vers l'entraînement incrémental (RISK-09, Q-06). Ce spike le dérisque avant M4, avec les outils existants
(nerfstudio/gsplat, kit docs/spikes/sp0/gpu) et les sessions déjà capturées, sans code mote.

Points de départ mesurés par SP-0 sur RTX 3070 : 20 dB atteints à la première évaluation (itération 2000, ~42 s),
donc une borne haute ; 30 000 itérations en ~24,5 min. Initialisation aléatoire, SO3xR3 actif.

Stratégies candidates (SPEC 11.4) : ajout de Gaussiennes dans les zones nouvellement couvertes, fenêtre glissante de
vues, ordonnancement des itérations entre vues récentes et anciennes. Garder le raffinement de pose SO3xR3, peu coûteux.
Mesurer aussi l'effet de la résolution réduite (mitigation de RISK-09). Attention : en nerfstudio 1.1.5, ns-render
dataset ne rend pas les vues du hold-out ; mesurer sur les rendus de ns-eval, comme train.py.
