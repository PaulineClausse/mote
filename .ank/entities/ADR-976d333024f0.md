- **Contexte** : nerfstudio 1.1.5 (ADR-da6e, entraînement hors ligne, utilisé par SP-0) déclare `protobuf !=3.20.0,<=3.20.3`. Le code Python généré de mote.v1 (WP-01, grpcio-tools 1.84.0) exige protobuf >= 7.35.1. Dans un même environnement, `from mote.v1 import mote_pb2` échoue. Les runtimes protobuf >= 4.21 refusent l'ancien code généré : il n'existe pas de version du code généré qui serve les deux. Constaté pendant WP-07 (TASK-239e). ADR-8d03 prévoit un seul paquet Python sous pc/.
- **Décision** : un seul paquet source sous pc/, mais deux environnements d'exécution.
  - **mote** (ingest, outils, éval) : protobuf 7, lit le MCAP.
  - **entraînement** (nerfstudio, gsplat, torch) : n'importe ni `mote.v1` ni le MCAP. Il ne lit que le répertoire de dataset (SPEC-3d2a §7.3 : images, `frames.jsonl`, `session.json`), qui est déjà l'interface entre l'ingest et l'entraînement. `mote train` lance l'entraînement dans un processus à part, dans son environnement (uv), et ne partage avec lui que des fichiers.
  - C'est déjà le fonctionnement de SP-0 et de SP-6, et celui du test `pc/tests/test_nerfstudio_load.py`. `[DECISION]` à ratifier.
- **Alternatives** :
  - un seul environnement, en figeant nerfstudio ou en le corrigeant pour qu'il accepte protobuf 7 : rien n'indique qu'il fonctionne avec ; et c'est une branche à maintenir ;
  - gsplat seul pour tout l'entraînement, sans nerfstudio (SP-6 le fait pour l'incrémental) : possible à terme, mais la passe finale perdrait splatfacto, référence de SP-0 ;
  - du JSON au lieu de protobuf côté Python : écarté par ADR-956c.
- **Conséquences** :
  - le répertoire de dataset devient un contrat à part entière, versionné (`session.json` : `dataset_version`) ;
  - l'aperçu live (WP-15) reçoit les nouvelles images par le système de fichiers ou par un canal sans protobuf, pas par un import de mote.v1 ;
  - deux verrous de dépendances à tenir dans pc/ : celui de mote et celui de l'entraînement.
- **Remise en cause si** : une version de nerfstudio accepte protobuf >= 7, ou l'entraînement se passe de nerfstudio.
