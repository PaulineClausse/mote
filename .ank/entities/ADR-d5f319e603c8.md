- **Contexte** : l'aperçu live veut des données fraîches (quitte à en sauter), l'archive veut des données complètes. Une seule file ne peut pas servir les deux.
- **Décision** : tout message est d'abord écrit dans le MCAP local, avec un numéro de séquence contigu par canal. Le flux live peut retirer des images et profondeurs en cas de saturation ou de coupure. L'ingest détecte les trous de séquence et demande leur renvoi (`ResendRequest`), servi depuis le fichier local en priorité basse pendant le scan, puis en totalité à la fin (`SessionEnd` annonce le dernier numéro de chaque canal). L'enregistrement local est donc obligatoire. `[DECISION]`
- **Alternatives** : flux fiable sans perte (bloque le live à la moindre coupure) ; fichier local facultatif (pertes définitives sur coupure).
- **Conséquences** : l'entraînement live travaille sur ce qui est arrivé ; l'entraînement final attend la session complète. Il faut de l'espace disque sur le casque (6.2).
- **Remise en cause si** : l'écriture locale systématique dégrade les performances du casque (SP-4).
